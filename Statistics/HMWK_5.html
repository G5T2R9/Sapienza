HMWK 5 — Riemann vs Lebesgue Integration & the Normal CDF

Pipeline: f on [a,b] → slice x (Riemann) / slice y + preimage measure (Lebesgue) → error vs exact → Φ(x): quadrature, series, erf → compare with reference

Ex. 1 – Riemann and Lebesgue Integration

Approximate ∫f for a collection of functions by cutting the domain (Riemann) and by cutting the range and measuring preimages (Lebesgue); compare accuracy, convergence and cost, and look at functions where the two views part ways.

Step 1: The two numerical schemes

Riemann: split [a,b] into n cells of width h = (b−a)/n and sample f at the cell midpoint.

Rn = h · Σi=0..n−1 f(a + (i+½)h)

Lebesgue: split the range [m,M] into n levels yj = m + j·k, k = (M−m)/n, and weight each level by the measure of the preimage Ej = {x : yj ≤ f(x) < yj+1}. With G(t) = μ{x : f(x) ≥ t} (the “layer-cake” function) this is a lower simple-function sum:

Ln = Σj=0..n−1 yj · μ(Ej) = Σj yj · ( G(yj) − G(yj+1) ),   G(yn) := 0

It is the discretisation of ∫f dμ = ∫0∞ G(t) dt (for f ≥ 0). Because f ≥ 0 is replaced by a simple function s ≤ f with f − s < k, we get 0 ≤ I − Ln ≤ k·(b−a): the Lebesgue sum is always a lower bound and converges at most linearly in the level height. The exact preimage measures G are available in closed form for the examples (e.g. μ{sin x ≥ t} = π − 2 arcsin t); for a general f they must be found by root-finding or by counting sample points.

Step 2: Code (core logic)

def riemann(f, a, b, n):                      # slice the domain
    h = (b - a) / n
    return h * sum(f(a + (i + .5) * h) for i in range(n))

def lebesgue(G, m, M, n):                     # slice the range, G(t) = mu{f >= t}
    k = (M - m) / n;  y = [m + j * k for j in range(n + 1)]
    g = [G(t) for t in y];  g[n] = 0          # nothing lies above the top level
    return sum(y[j] * (g[j] - g[j + 1]) for j in range(n))

Functions: sin x on [0,π]; x² on [0,1]; step 1/3 (1 for x<½, 3 after); |x−½|; 1/√x on (0,1] (truncated at T = √n for the Lebesgue sum, see Step 4); step 1/0; sin x / x on [0,π] (exact value Si(π) = 1.851937…, preimages by bisection since f is decreasing).

Step 4: Accuracy, convergence, efficiency

  • Smooth functions. The midpoint rule is second order (error ≈ (b−a)h²f″/24); the Lebesgue sum is first order, error ≈ k·(b−a)/2 — at n = 10⁴, 10⁻⁹ versus 10⁻⁴. Both converge to the same value, as they must: for Riemann-integrable f the Riemann and Lebesgue integrals coincide.
  • Discontinuous f. The Lebesgue view is unaffected by where the jump sits (only the measures of the level sets matter); Riemann loses its order to O(1/n) as soon as a cell straddles the jump.
  • Unbounded f = 1/√x. Riemann: f(0) is infinite, so only an improper limit exists (midpoint avoids x = 0 and error ∝ √h). Lebesgue: ∫f = lim ∫min(f,T) by monotone convergence, and G(t) = min(1, 1/t²) gives ∫0∞G = 1 + 1 = 2. The truncation costs 1/T, hence T = √n and k = n−1/2.
  • Cost. Riemann needs n evaluations of f and is trivially vectorised. Lebesgue needs the preimage measure: closed form or bisection per level (≈50 evaluations of f each for sin x / x), or counting N sample values in bins (O(N) or O(N log N)), which is then just a Riemann sum whose values are rounded down to the level grid — never better than Riemann for continuous f, but valid for any measurable f and any measure.

Step 5: Pathological functions

Dirichlet 1ℚ∩[0,1]. Every cell contains both rationals and irrationals, so every lower Darboux sum is 0 and every upper sum is 1: not Riemann integrable. A Riemann sum depends on the tags: rational tags ξi = i/n give Rn = 1 for all n, tags ξi = (i+√2−1)/n·(…irrational) give 0. (A floating-point program cannot even decide rationality — every double is a rational number — so this experiment can only be done symbolically.) Lebesgue: ℚ is countable, μ(ℚ∩[0,1]) = 0 (cover the k-th rational by an interval of length ε/2k), so G(t) = 0 for t>0 and ∫ = 0 exactly.

Thomae f(p/q) = 1/q. For any ε > 0, {f ≥ ε} is finite, so μ{f ≥ ε} = 0 and the Lebesgue integral is 0. It is also Riemann integrable (upper sums ≤ ε + (finite number of points)·h) with the same value 0 — the two definitions agree. With rational tags i/n, f(i/n) = gcd(i,n)/n and Rn = (1/n²) Σi gcd(i,n):

Ex. 2 – Numerical Computation of the Normal CDF

Compute Φ(x) = ∫−∞x φ(t)dt with φ(t) = e−t²/2/√(2π), explain why no elementary formula exists, and test three families of methods against a reference.

Step 1: Φ and the error function

By symmetry Φ(x) = ½ + ∫0x φ. The substitution t = u√2 turns it into the error function erf(z) = (2/√π)∫0z e−u²du:

Φ(x) = ½ [ 1 + erf( x/√2 ) ] = ½ erfc( −x/√2 )

This is an exact analytic representation — but erf is only a name for the integral. Evaluating it still requires a numerical algorithm, which is why every library (libm, SciPy, R, …) ships a carefully tuned erf/erfc implementation.

Step 2: Why Φ is not elementary (Liouville)

Liouville’s theorem (1835). For rational f, g with g non-constant, ∫ f·eg dx is an elementary function iff there is a rational R with R′ + g′R = f; the antiderivative is then R·eg.

Here f = 1, g = −x²/2, so g′ = −x and we need a rational R with

R′ − x·R = 1

Pole of order m ≥ 1 at some a: R′ has order m+1, xR at most m, so the left side has a pole but the right side (=1) does not — impossible. So R is a polynomial of degree d: R′ has degree ≤ d−1, xR has degree d+1, hence the left side has degree d+1 ≥ 1 (R = 0 gives 0 ≠ 1). Contradiction: no elementary antiderivative of e−x²/2 exists, so neither Φ nor erf can be written with finitely many exp, log, roots, trigonometric functions and algebraic operations.

The same equation shows where the series comes from: S′ = 1 + xS is solved by the entire power series S(x) = Σ x2k+1/(2k+1)!! (not rational), and e−x²/2S(x) is the antiderivative — see method B.

Step 3: Three numerical approaches

A. Quadrature on [0,|x|] with n panels (h = |x|/n), then Φ(−x) = 1 − Φ(x):

Trapezoid: h[½φ(0) + Σi=1..n−1φ(ih) + ½φ(x)]  (error O(h²))
Simpson: (h/3)[φ(0) + 4Σoddφ(ih) + 2Σevenφ(ih) + φ(x)]  (error O(h⁴))

B. Power series. Integrating the Maclaurin series of e−t²/2 gives an alternating series; the equivalent form from Step 2 has only positive terms and no cancellation:

Φ(x) = ½ + φ(x) · Σk≥0 x2k+1 / (1·3·5···(2k+1)),  termk = termk−1 · x²/(2k+1)

C. erf-based. Φ(x) = ½[1 + erf(x/√2)] with (i) the alternating erf series, (ii) the Abramowitz–Stegun 7.1.26 rational approximation erf(z) ≈ 1 − (a₁t + … + a₅t⁵)e−z², t = 1/(1+0.3275911z), |error| ≤ 1.5·10⁻⁷, and (iii) a hybrid: series for |x| < 3, and for the tails the continued fraction

1 − Φ(x) = φ(x) / ( x + 1/( x + 2/( x + 3/( x + … ))) ),  x > 0  (80 levels)
def Phi(x):                                   # hybrid, ~1e-16 relative accuracy
    if abs(x) < 3:
        t = s = x; k = 0
        while abs(t) > 1e-17 * abs(s):
            k += 1; t *= x*x / (2*k + 1); s += t
        return 0.5 + exp(-x*x/2) / sqrt(2*pi) * s
    d = 0.0
    for k in range(80, 0, -1): d = k / (x_abs + d)      # continued fraction
    q = exp(-x*x/2) / sqrt(2*pi) / (abs(x) + d)          # upper tail Q(|x|)
    return 1 - q if x > 0 else q

Step 6: Summary

  • Φ has no elementary closed form (Liouville: R′ − xR = 1 has no rational solution); the special function erf gives the exact representation Φ(x) = ½[1 + erf(x/√2)], but erf itself must be computed numerically.
  • Best practical choice: erfc-based evaluation — series near 0, continued fraction (or Cody’s rational approximations, as in libm) in the tails — which keeps relative accuracy ≈10⁻¹⁶, including Φ(−6) ≈ 10⁻⁹.
  • Quadrature is the most general method (it works for any density) but is the least efficient here; Simpson is the better of the two quadratures by orders of magnitude at equal cost.
